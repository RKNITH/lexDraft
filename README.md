# LexDraft – Online Legal Document Generator

A modern, fully responsive legal document generator built with React.js (Vite), Tailwind CSS, and Framer Motion.

## Features
- 7+ professional legal document templates (NDA, Employment Contract, Lease Agreement, etc.)
- Live document preview as you type
- Export as PDF or .txt
- Save documents locally (localStorage)
- Search & filter templates by category
- Fully responsive (mobile, tablet, desktop)
- Beautiful animations with Framer Motion
- Dark/professional design aesthetic

## Tech Stack
- **Frontend**: React.js 18 + Vite 5
- **Styling**: Tailwind CSS 3
- **Animations**: Framer Motion 10
- **PDF Generation**: jsPDF
- **Forms**: React Hook Form
- **Routing**: React Router DOM 6
- **Notifications**: React Hot Toast

## Getting Started

1. Clone the repository
2. Copy `.env.example` to `.env` and configure:
   ```
   cp .env.example .env
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm run dev
   ```
5. Open http://localhost:5173

## Build for Production
```
npm run build
npm run preview
```

## Environment Variables
| Variable | Description | Default |
|----------|-------------|---------|
| VITE_APP_NAME | Application name | LexDraft |
| VITE_APP_VERSION | App version | 1.0.0 |
| VITE_APP_DESCRIPTION | App description | Professional Legal Document Generator |
| VITE_CONTACT_EMAIL | Support email | support@lexdraft.com |

## No Backend Required
This application is entirely frontend-based. Documents are generated client-side using JavaScript templates and saved to the browser's localStorage. No server or database is needed.
